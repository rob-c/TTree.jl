TTree — Module
TTree

A pure-Julia reader and writer for ROOT files.

using TTree

TTree.open("events.root") do f
    keys(f)
end

Local paths, root:// URLs and http(s):// URLs are all opened the same way; remote access goes through XRootD.jl.

Layers

The package is built as a stack, each layer usable on its own:

  • TTree.Bytes — ROOT's serialization format as byte codecs.
  • TTree.Compress — ROOT's compression envelope.
  • TTree.IOFS — the file container: keys, directories, headers.
  • TTree.Objects — ROOT's classes: collections, streamer info.
  • TTree.Trees — trees, branches, leaves and baskets.

Read and write are implemented as mirror images at every layer, so a file this package writes decodes with the same code that reads one ROOT wrote.

create(target; compression=Compress.DEFAULT_SETTINGS, kwargs...) -> ROOTFile
create(f, target; kwargs...)

Create a ROOT file and return it open for writing.

compression is a Compress.Settings or a packed fCompress integer; it becomes the file's default for every object written into it.

TTree.open — Method
open(target; kwargs...) -> ROOTFile
open(f, target; kwargs...)

Open a ROOT file for reading.

target may be a path, a root://, http(s)://, dav(s):// or s3:// URL, an IO, or a byte vector. Keyword arguments are passed to the underlying source, which is where remote credentials go.

The two-argument form closes the file when f returns, including on error.
